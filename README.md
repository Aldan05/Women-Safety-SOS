# 🚨 SOS Activation – Women Safety App

### Smart Emergency Alert System for Personal Safety

SOS Activation is an Android application designed to help women request emergency assistance quickly. The application aims to provide instant SOS activation, emergency contact notifications, and GPS-based location sharing to support faster responses during critical situations.

## 🎯 Objectives

- Improve personal safety through quick emergency alerts.
- Enable users to contact trusted people during emergencies.
- Share location information to help emergency contacts identify the user's whereabouts.
- Provide a simple, accessible, and user-friendly interface.

## ✨ Key Features

- **One-Tap SOS:** Activate an emergency alert quickly.
- **Voice-Activated SOS:** Trigger emergency alerts using voice commands.
- **GPS Location Sharing:** Share the user's location with trusted contacts.
- **Emergency SMS:** Send emergency messages to configured contacts.
- **Shake Activation:** Planned feature to trigger SOS through phone movement.
- **Emergency Contact Management:** Manage trusted contacts.
- **Emergency Dashboard:** Planned interface for monitoring emergency alert status.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Development Environment:** Android Studio
- **UI Design:** XML
- **Location Services:** GPS / Android Location APIs
- **Emergency Communication:** SMS functionality

## ⚙️ How It Works

1. The user configures trusted emergency contacts.
2. The user activates SOS using the available activation method.
3. The application obtains the user's location, subject to device permissions and GPS availability.
4. An emergency message containing available location information is sent to configured contacts.
5. The contacts can use the shared location to help the user.

## 🚀 Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/Aldan05/Women-Safety-SOS.git
   ```

2. Open Android Studio.
3. Select **Open** and choose the cloned project folder.
4. Allow Gradle synchronization to complete.
5. Connect an Android device or start an emulator.
6. Build and run the application.
7. Grant the required permissions and configure emergency contacts.

## 🧪 Testing

Test the application for:

- SOS activation and cancellation.
- Location permission handling.
- GPS availability and location accuracy.
- Emergency message delivery.
